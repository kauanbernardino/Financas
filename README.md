# Finanças

Projeto de um WEB APP de getao pessoais com consultas SQL

## O que já funciona
- Banco de dados em SQL (SQLite) com as tabelas Despesas, Entradas, tipoEntradas e tipoSaida
- Consultas em SQL: Consultas gerais basicas de SQL SUM, GROUP BY, JOIN ETC
- Java conectado ao banco com JDBC :sqlite_jdbc
- Saldo calculado

## Tecnologias
- Java
- SQL (SQLite)
